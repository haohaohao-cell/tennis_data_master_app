# 网球数据方案简明版

# 网球数据统计与 Web 看板需求

## 一、统一约定

前端、后端、数据库、数据文件在描述同一数据项时统一使用以下字段名。

### 1. 命名规则

- 字段统一使用 `snake_case`
- 数量：`_count`
- 比例：`_rate`
- 评分：`_score`
- 平均值：`avg_`
- 最大值：`max_`
- 标准差：`_std`
- 时间：`_ms`
- 距离：`_m`
- 场地坐标：`_x_m`、`_y_m`
- 面积：`_m2`
- 速度：`_mps`
- 像素：`_px`
- 比例统一保存为 `0～1`
- 评分统一为 `0～100`

### 2. 落库字段与非落库字段

- 落库字段以《网球数据库设计》中的 `users`、`lessons`、`lesson_students`、`tennis_activities`、`videos`、`video_shares`、`social_posts`、`post_media`、`points`、`shots` 为准。
- 本文中的 Web 看板指标、趋势、诊断、可视化点、视频片段，以及明细页中的计算/展示字段，除非同时出现在当前核心落库表中，均标记为 `非落库字段`。
- `非落库字段` 由数据库字段、逐帧数据文件和算法结果计算得到，不要求为每个展示指标单独新增落库列。

### 3. 实施阶段

- **P0**：基础数据直接统计，第一版完成
- **P1**：需要规则推断，第一版后期完成
- **P2**：复杂战术、长期模型或群体模型

### 4. 所有统计结果公共字段

以下字段用于统计结果载荷，属于 `非落库字段`。

| 字段 | 含义 |
| --- | --- |
| `video_id` | 视频 ID |
| `player_slot` | 球员 A 或 B |
| `metric_code` | 本文定义的指标字段名 |
| `metric_name` | 指标显示名称 |
| `metric_value` | 指标值 |
| `metric_unit` | 单位 |
| `sample_size` | 样本量 |
| `scope_type` | video、activity、lesson、set、game、point、history |
| `scope_id` | 对应范围 ID |
| `dimension` | serve、return、rally、movement 等 |
| `confidence` | 统计可信度 |
| `algorithm_version` | 算法版本 |
| `created_at` | 创建时间 |

## 3. 分数结束原因

| 数据 | 字段名 | 阶段 |
| --- | --- | --- |
| Ace 数量 | `ace_count` | P0 |
| 发球直接得分数 | `service_winner_count` | P0 |
| 制胜分数 | `winner_count` | P0 |
| 双误数 | `double_fault_count` | P0 |
| 受迫失误数 | `forced_error_count` | P1 |
| 非受迫失误数 | `unforced_error_count` | P1 |
| 受迫类型未知的失误数 | `unknown_forcedness_error_count` | P1 |
| 下网失误数 | `net_error_count` | P0 |
| 出界过长数 | `long_error_count` | P0 |
| 出界过宽数 | `wide_error_count` | P0 |

简单规则：

- `winner`：球落在界内，对手未完成有效回球。
- `forced_error`：失误前来球压力较高。
- `unforced_error`：失误前来球压力较低。
- 无法可靠区分受迫或非受迫时使用 `error_forcedness = unknown`；无法判断分统计结果时使用 `point_result = unknown`。
- `points.ending_reason` 中出界统一为 `out`；`long_error_count` 和 `wide_error_count` 从终结拍 `shots.error_type = long / wide` 统计。

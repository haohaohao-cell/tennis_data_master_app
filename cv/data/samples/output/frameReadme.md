## 🎾 网球分析逐帧数据 (Frames Data) README

### 1. 全局配置 (`metadata`)
* **`version`**: 数据格式版本（1.1.0）。
* **`fps`**: 视频帧率（如 30.0），用于将帧索引转换为时间戳。
* **`video_width / height`**: 原始视频分辨率，用于反推像素坐标在画面中的比例。
* **`court_dimensions`**: 场地的物理定义。包含长度（23.77m）和宽度（10.97m），这是单应性变换（Homography）的基础。

---

### 2. 帧数据序列 (`frames`)
这是一个数组，每一项代表视频中的一帧。

#### A. 基础属性
* **`frame_index`**: 帧编号，从 0 开始。
* **`time_sec`**: 当前帧在视频中的时间点（单位：秒）。计算方式为 `frame_index / fps`。

#### B. 球体信息 (`ball`)
* **`pixel`**: `[x, y]` 视频画面中的像素坐标。如果本帧未检测到球，则为 `null`。
* **`court`**: `[x, y]` 映射到网球场平面后的**物理坐标**（单位：米）。这对于计算球速和判定界内外至关重要。



#### C. 球员信息 (`players`)
一个包含两名球员数据的数组：
* **`id`**: 球员唯一标识。通常 `1` 代表画面底部（Bottom）球员，`2` 代表画面顶部（Top）球员。
* **`bbox_pixel`**: `[x1, y1, x2, y2]` 球员在画面中的边界框（Bounding Box）。
* **`feet_court`**: `[x, y]` 球员脚部中点对应的**场地物理坐标**。用于计算球员的跑动距离和体能消耗。

#### D. 事件标志 (`events`)
记录该帧发生的关键动作，是逻辑判定的“触发器”：
* **`is_hit`**: 布尔值。为 `true` 时表示本帧发生了击球动作。
    * `hitter_id`: 击球者的 ID（1 或 2）。
    * `shot_type`: 击球动作分类（如 `Serve`, `Smash`, `Forehand` 等）。
* **`is_bounce`**: 布尔值。为 `true` 时表示球在本帧触地。
    * `bounce_type`: 落地判定结果（`in` 界内, `out` 界外）。
    * `bounce_pixel / court`: 触地点的精确像素和物理坐标。
* **`is_net_hit`**: 布尔值。为 `true` 时表示球击中了球网或落入网区。
    * `net_confidence`: 判定置信度。



---

### 3. 数据层级与关联逻辑

1.  **时序连续性**：算法通过读取连续帧的 `ball.court` 坐标来拟合抛物线，平滑掉检测不到球的 `null` 帧。
2.  **坐标转换关系**：
    * `pixel` 坐标用于：在视频画面上叠加 UI 框、渲染网球拖尾。
    * `court` 坐标用于：计算两帧之间的位移 $\Delta d$，结合 $\Delta t$ 得出物理时速。
3.  **事件驱动分析**：
    * 当监听到 `is_hit: true` 时，系统会重置“当前拍”的计时，并开始计算“出球速度”。
    * 当监听到 `is_bounce: true` 时，系统根据 `bounce_court` 的位置与场地边界进行比对，验证 `bounce_type` 的准确性。
